# Simply Bargains

Simple public site for **Simply Bargains** (home & household bargains).

## Local preview

Open `index.html` in a browser, or:

```bash
npx --yes serve .
```

## Deploy on Vercel

1. Sign in at [vercel.com](https://vercel.com) with GitHub (`danimok`).
2. Import this repository.
3. Deploy with defaults (static site; no build command needed if Vercel serves `index.html` from the root).
4. Copy the `*.vercel.app` URL for Meta Commerce domain verification.
